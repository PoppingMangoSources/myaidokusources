## Usage

Add the source list with the button above, or paste the URL into **Settings → Source Lists** in Aidoku. Individual sources can be installed by opening their `.aix` on an iOS device.

Requires **Aidoku 0.8** or newer. Refresh the list in Aidoku to pick up source updates.
